盈利较好的闭环：603328 +9.95%、601208 +7.86%、603588 +6.61%、605589 +2.80%、600793 +2.42%。亏损较大的闭环：002265 -5.90%、300162 -4.87%、300708 -4.32%、600016 -4.31%、002023 -3.80%。

## BUY 与 SELL 联合结论

- **有效组合**：早期突破/贴 pivot + 回踩不破 + 收回均价/低点抬高。600793、603588、603328 属于这类，均实现盈利。
- **单独“放量”不够**：002023、300708 等虽然有突破和量价描述，但随后跌破均价或失败突破，卖出仍亏损。
- **低位确认仍需执行时点**：600623、600210、601360、002191 都写了回踩/低位证据，但很快触发风险退出，说明“回踩”必须和指数环境、后续均价保持结合，而不是一次收回就视为成立。
- **SELL 阀门总体发挥了保护作用**：多个亏损单在跌破均价、MA20、反抽失败后退出；但从实际成交看，当前 BUY 组合仍是负期望，主要问题是买入后延续性不足，而不是 SELL 完全失效。

下一步 prompt 应把 BUY 证据改成组合条件：`趋势未坏 + 低位/中部 + 回踩后收回均价 + 低点抬高`，并要求 execution_manager 在 SELL 时保留实际成交价和触发证据，继续按已实现收益评价。
