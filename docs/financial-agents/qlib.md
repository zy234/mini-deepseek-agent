# microsoft/qlib

- 地址：https://github.com/microsoft/qlib
- 调研快照：约 48k Star，MIT，最近提交 2026-07-23
- 定位：AI-oriented quantitative investment platform，覆盖数据、因子、模型、回测、组合和执行。

## 仓库实现方案

Qlib 提供完整量化研究流水线，支持监督学习、市场动态建模和强化学习，并覆盖 alpha 挖掘、风险建模、组合优化和订单执行。它更像研究后端和实验平台，规模、数据格式和配置体系都远超当前小型 Agent。

## 适合迁移的部分

- 因子研究的明确输入/标签/时间切分。
- 统一回测指标和实验记录。
- 研究、模型、组合和执行分层。
- 以 point-in-time 数据和严格 train/test 边界避免前视偏差。

## 当前框架中的实现建议

第一阶段只实现一个简化 `factor_score` 工具：读取已验证的 snapshot，计算少量可解释因子，返回横截面排名和缺失值统计。实验记录保存因子版本、数据 hash、训练区间、测试区间和交易成本假设。

如果未来确实需要机器学习，再让 Agent 负责提出因子假设和实验配置，由宿主脚本执行训练和回测。Agent 不应直接修改生产策略或跳过时间切分。

## 不应直接引入的部分

- Qlib 全套数据仓库、模型库和 RL 环境。
- 未经审计的默认数据集和指标。
- 用 LLM 生成因子后直接宣称存在 alpha。

## 验证要求

每个实验必须通过数据完整性、身份 hash、时间边界、交易成本和基准对比检查。至少保留一个真正无信号的负对照和一个可检测的正对照，避免把随机结果误判为策略能力。
